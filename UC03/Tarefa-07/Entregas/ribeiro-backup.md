

# Procedimento Técnico — UC 3: Clonagem com Clonezilla (Disco para Disco)

**Aluno(a):** Pedro Henrique Ribeiro da Silva 

**Tema:** Clonagem de Disco para Disco utilizando Clonezilla

## 1. Objetivo

O procedimento de clonagem com Clonezilla tem como objetivo copiar todos os dados de um disco para outro, incluindo sistema operacional, arquivos e partições. Esse processo permite substituir discos ou transferir informações para uma nova unidade de armazenamento.

## 2. Ferramentas e Cuidados Técnicos

- **Ferramentas / Softwares:**
  - Computador ou máquina virtual.
  - Programa Clonezilla.
  - Dois discos virtuais ou físicos (origem e destino).
  - Imagem ISO do Clonezilla, se utilizada na inicialização.

- **Segurança / Boas Práticas:**
  - Fazer backup dos arquivos importantes.
  - Identificar corretamente os discos de origem e destino.
  - Verificar se o disco de destino possui espaço suficiente.
  - Não interromper o processo de clonagem.
  - Conferir as configurações antes de iniciar.

## 3. Passo a Passo

**1. Preparação:** Inicie o computador ou a máquina virtual e verifique se os dois discos estão disponíveis.

**2. Inicialização:** Inicie o Clonezilla pelo método utilizado na atividade, sem utilizar pendrive.

**3. Configuração inicial:** Selecione o idioma, configure o teclado e escolha a opção de iniciar o Clonezilla.

**4. Seleção do modo:** Escolha a opção de clonagem de dispositivo para dispositivo (device-device).

**5. Identificação dos discos:** Identifique cuidadosamente o disco de origem e o disco de destino.

**6. Confirmação:** Confira todas as informações e confirme a operação somente após verificar os discos selecionados.

**7. Clonagem:** Aguarde o Clonezilla copiar os dados e as partições do disco de origem para o disco de destino.

**8. Finalização:** Aguarde a conclusão do processo e encerre o Clonezilla conforme as orientações exibidas na tela.

## 4. Como Validar (Teste Final)

- [ ] **Teste 1:** Verificar se o disco de destino possui as mesmas partições do disco de origem.
- [ ] **Teste 2:** Conferir se os arquivos foram copiados corretamente.
- [ ] **Teste 3:** Testar se o sistema consegue iniciar pelo disco clonado, quando aplicável.
