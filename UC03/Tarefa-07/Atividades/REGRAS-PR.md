# Regras da Esteira (Leia antes de enviar seu PR)

Para que seu Pull Request seja aprovado (`Merge`), siga estes 4 critérios obrigatórios:

1. **Fork e Branch:** Nunca envie alterações direto da sua branch `main`. Crie uma branch com o padrão `docs/seu-nome` (ex.: `docs/maria-souza`).
2. **Apenas 1 Arquivo:** Crie **somente um arquivo `.md`** dentro da pasta `entregas/` usando o modelo de `MODELO-DOCUMENTO.md`. Não altere os arquivos da raiz.
3. **Nome do Arquivo (`kebab-case`):** Use apenas letras minúsculas, sem acentos e separadas por hífen:
   * ✅ Correto: `entregas/maria-souza-nome-procedimento.md`
   * ❌ Errado: `entregas/Atividade da Maria.md`
4. **Commit Descritivo:** Exemplo: `docs: adiciona procedimento yyyyy de maria souza`
