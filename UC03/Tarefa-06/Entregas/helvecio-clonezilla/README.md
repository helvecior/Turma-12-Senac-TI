## Preparação da branch de homologação

Para usar estes arquivos em um repositório Git já configurado, abra a raiz do repositório no VS Code. Antes de incorporar a documentação, atualize a cópia local e crie a branch da atividade no terminal integrado.

```bash
git checkout main
git pull origin main
git checkout -b homologacao-clonezilla
git branch
```
