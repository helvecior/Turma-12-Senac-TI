## Como contribuir

Os materiais podem ser organizados e atualizados na branch correspondente à unidade curricular. Ao adicionar novos conteúdos, procure manter os arquivos claros e bem organizados para que todos possam encontrá-los com facilidade.

Para a adição de novos materiais, siga os passos abaixo:

1. Adicione os novos materiais na branch criada.
1. Envie as alterações para o repositório remoto.
1. Crie um pull request para mesclar as alterações na branch principal.
